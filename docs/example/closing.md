# Make your own deck

1. Create a Zensical project for your deck, or use an existing project.
2. Install Decksical and select its theme in `zensical.toml`.
3. Create one Markdown file per slide and put `template: slide.html` in its Markdown header.
4. List the slides in a navigation section, in presentation order.
5. Preview the deck with `zensical serve`.

Use the **Right arrow** and **Left arrow** keys to move between slides. Press
**Escape** to return to the deck overview. The example source files are
available to adapt for your own presentation.
