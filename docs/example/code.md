# Code in slides

Use `inline code` for names and short expressions. Add a language name after
the opening fence to highlight a longer example. The colors follow the active
theme variant.

```python
def greet(name):
    return f"Hello, {name}!"

print(greet("Zensical"))
```

Inline highlighting also works: `#!python greet("Decksical")`.
