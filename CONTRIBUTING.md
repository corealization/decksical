# Contributing

Thanks for your interest in Decksical. Bug reports and feature requests are welcome through the [issue tracker].

## Report a bug

Before opening an issue, check whether someone has already reported the problem. Include a minimal example that reproduces it, along with the Decksical and Zensical versions, the theme variant, and the browser you used. The example should be a small project that makes the problem easy to reproduce. Describe what you expected and what happened instead.

## Request a feature

Describe what you are trying to do and how the feature would help. An example of the Markdown or configuration you have in mind can make the request easier to understand.

## Pull requests

I am not accepting pull requests at this time. Please open an issue to report a problem or discuss an idea instead.

[issue tracker]: https://github.com/corealization/decksical/issues
