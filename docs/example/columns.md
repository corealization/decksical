# Two columns of Markdown

## Arrange your content

The marker separates left and right content.

- Use text, lists, code, or images.
- Use one `<!-- column-break -->` per slide.
- Keep related ideas together.

The slide heading spans both columns.

## Select the theme

After installation, select the theme in `zensical.toml`:

```toml
[project.theme]
name = "decksical"
font = false
```

Use `font = false` for system fonts.
