# Presentations with Zensical

Choose Decksical when you want your slides to fit a text-based, version-controlled
workflow rather than a single PowerPoint file.

- Write and review each slide as a plain Markdown file.
- Use Zensical's authoring features, including code, diagrams, and maths.
- Present the published site in a browser, with no separate slide file to export.
- Keep the deck in its own project or alongside a site's documentation.

This workflow suits content that benefits from readable source files and
version history.
