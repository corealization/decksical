# Keep your notes with your slide

Add an optional notes block at the end of your Markdown file:

``` markdown
??? notes "Speaker notes"

    Remind yourself what to explain here.
```

Press **N** to show or hide your speaker notes. Your browser remembers the
choice between slides and when you return to the presentation.

Notes appear below the slide content. This is the only slide in this deck
with notes, so try the shortcut here.

??? notes "Speaker notes"

    - Explain that notes are optional and hidden by default.
    - Show the indented Markdown block that defines them.

    Notes can contain links, lists, and other Markdown content. They take up
    space below the slide when shown. Printing includes them when visible;
    hide them before printing to omit them.
