# Author a slide

Start the file with a YAML header that selects the slide template, then write
the slide content in Markdown:

```
---
template: slide.html
---

# Explain one idea

- State the main point.
- Add only the details that support it.
```

Use Markdown for headings, lists, emphasis, and links. Zensical also provides
richer authoring options, which the following slides demonstrate.
Split dense material across slides; longer content scrolls rather than shrinking.
